`collection` = 各馆内部的**子专藏标识**（来自各馆数据的 `partof`/fonds 归属）：

直接显示技术 slug 确实奇怪——明日改为中文友好标签（见任务 4）。**slug 本身不改**：
它是落盘路径 `data/books/<馆>/<专藏>/<条目>/` 的一部分，改名会导致已有文件失联。

### 数据保存位置与 NAS 映射（现状已安全，已实测）
```
NAS:  /share/Container/eightnations/data   ←—— docker volume ——→   容器 /data
      ├── db/library.db              书目/任务/审核状态/事件（唯一状态源）
      ├── books/<馆>/<专藏>/<条目>/   book.pdf(+分卷) · cover.jpg · meta.json
      ├── snapshots/                 目录快照与条目详情（可重导）
      ├── runtime/throttle/          跨进程节流锁（自动生成）
      └── logs/                      scheduler / web 日志
```
- `docker-compose.yml` 已挂载上述路径；容器重建（`pull && up -d`）只换镜像层，
  **不触碰数据卷**——2026-09-19 已实测：重建前后 2,128 书 / 44 任务 / 42 PDF /
  141 分类完全一致，抽检 PDF 可读。
- 代码全部用 `EIGHTNATIONS_DATA=/data` 定位数据，无散落写入（临时分卷 chunk 写
  `/tmp`，属可丢弃中间产物）。

## 任务 1 · 书名日文新字体 → 繁体汉字显示 ✅（映射 25+120 字，60/100 题名转换）

**问题**：日本馆题名是新字体（欽定古今**図**書集成 / 太平御**覧**），观感不符。

**方案**：opencc 库无 `jp2t` 配置（已核实，仅 s2t 系），自建映射：
- 新增 `core/text.py`：`SHINJITAI_MAP`（新字体→繁体/旧字体，目标覆盖 150-250 字：
  図国楽済権絵辞売発変気広処帯画県軽験験続譲etc.）+ `jp2t()` 转换函数；
- Jinja 过滤器 `|jp2t`，应用于 书库卡片题名 / 审核列表 / 详情页（题名、著者、主题）；
  **只改显示，不改库**（库内保留馆方原始值，meta.json 同样保留原始值）；
- 自检脚本：对全库 2,100+ 题名跑转换，列出仍未映射的可疑字符，迭代补表；
- `requirements.txt` 无需新增依赖。

**验收**：书库/审核/详情页日本馆书名全为繁体；LoC/BnF 中文题名不受影响（映射不命中原样返回）。

## 任务 2 · 朝代筛选：多选 + 反选 + 未知 ✅（unknown 筛出 76 册）

**现状**：单选下拉，且无法筛"未知朝代"（当前库中 76 册：LoC 善本 69 + 日本 7）。

**方案**：
- 后端：`era` 参数接受逗号多值（`era=宋,明`），SQL 改 `era IN (...)`；
  新增 `era=unknown` 映射 `era=''`（"未知"也是一个可筛值）；
- 前端：筛选条改为 checkbox 药丸组（唐/宋/元/明/清/民国/未知）+ **反选**按钮
  （一键取当前未选项）；书库页与审核页同步改造；
- 默认全不选 = 不筛选（保持现行为）。

**验收**：多选并集结果正确；反选一键生效；"未知"筛出 76 册。
